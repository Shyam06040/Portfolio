# Shyamkumar Nahate – Portfolio

Static portfolio site (single `index.html`, no build step).

## Host on GitHub Pages
1. Create a new repository named `Shyam06040.github.io` (or any name, e.g. `portfolio`).
2. Upload `index.html` and `README.md` to the repository root.
3. Go to Settings → Pages → set Source to "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. Your site goes live in about a minute at `https://shyam06040.github.io/` (or `https://shyam06040.github.io/portfolio/` for a differently named repo).
